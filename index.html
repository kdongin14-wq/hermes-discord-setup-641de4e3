휴대폰용 암호화 등록

토큰 원문은 채팅에 보내지 마세요. 이 파일은 서버로 토큰을 전송하지 않습니다. 휴대폰에서 암호화한 JSON 파일만 보내는 절차입니다.

1. 먼저 암호화 준비 상태 확인

이 HTTPS 페이지를 아이폰의 사파리 또는 크롬에서 여세요. 아래에 초록색 ‘암호화 준비 완료’가 표시되는지 확인하세요.

암호화 기능 확인 중… 이 문구가 바뀌지 않으면 토큰을 입력하지 마세요.

2. 새 봇의 토큰만 입력

초록색 ‘암호화 준비 완료’가 표시된 경우에만 Discord 개발자 포털의 Hermes agent → Bot → Reset Token(토큰 초기화)에서 발급하세요. 인증은 Discord 화면에서 직접 완료합니다.

대상 애플리케이션: 1558973888808091718

토큰이 보이는 화면은 캡처하지 마세요. 생성 후 입력칸은 비웁니다.

3. 암호화된 파일만 보내기

암호화 JSON 파일 다운로드

내려받은 hermes-discord-encrypted-…json 파일을 지금 대화 중인 텔레그램 채팅에 ‘파일’로 첨부하세요.

파일 다운로드가 안 된다면: 암호화된 텍스트 보기

아래는 토큰 원문이 아니라 암호문입니다. 전체를 복사해서 이 채팅에 보내도 됩니다.

진행 상태와 주의사항

  • 이 파일 자체로 봇이 온라인이 되지는 않습니다. 암호문을 받은 뒤 PC에서 검증·등록하는 단계가 남습니다.
  • 복호화용 개인키는 Hermes가 실행되는 PC에만 저장돼 있습니다. 이 HTML에는 공개키만 있습니다.
  • 네트워크 전송 기능, 외부 스크립트, 분석 도구, 브라우저 저장소를 사용하지 않습니다.
  • 휴대폰 브라우저에서 암호화가 지원되지 않으면 입력을 차단합니다. 토큰을 채팅에 붙여넣는 대체 방식은 사용하지 마세요.
  • 기존 Telegram 설정은 아직 변경하지 않았습니다.
